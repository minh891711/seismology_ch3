3.1 緒論

概述 地震學透過地震波走時推導地球內部速度結構，進而約束礦物與熱狀態。
解析力 地震學可精確描述CMB、地殼與地函界面，優於重力與磁力方法。
走時與反演 走時 = 接收時間 - 發震時間 為慢度沿射線的積分，需多測站資料才能反演。

3.2 地震折射法

平面層法 直達波：T = x/v₀ 首波：T = x/v₁ + τ 存在交叉距離
傾斜層 需雙向測量 v_u ≠ v_d
限制 低速層 → 無首波 → 深度誤判

3.3 地震反射法

走時雙曲線 T² = x²/v² + t₀²
CMP 共中點疊加提升訊號品質
偏移 修正傾斜造成的假象

3.4 球形地球

Snell定律 p = r sin i / v
三重化 速度急變 → 多條射線
陰影帶 低速層 → 無波到達

3.5 實體波走時

地球模型 地殼 → 地函 → 外核 → 內核
震相 P, S, PP, PKP, PKIKP

3.6 各向異性

來源 SPO、LPO
剪切波分裂 一個波 → 兩個不同速度

3.7 衰減

原因 幾何擴散、散射、非彈性
Q值 Q越大 → 衰減越小

3.8 地函與地核組成

密度 平均5.5 g/cm³ → 存在高密度核心
地函 主要為橄欖岩（pyrolite）
地核 鐵 + 輕元素
